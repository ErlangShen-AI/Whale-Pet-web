小鲸鱼桌宠

把界面右下角的那只小鲸鱼搬到 Android 桌面。鲸鱼可以拖到屏幕任意位置、贴边吸附、按压回弹， 气泡里实时显示 DeepSeek 账户余额与今日用量。

特性

  • 悬浮桌宠

    拖动时与手指一比一跟随，坐标夹在系统栏以内的安全区，松手按落点吸附到最近的边。

  • 贴边镜像

    左缘吸附整体水平镜像，气泡文字同步反向翻转后仍可读。

  • 按压回弹

    按压 Q 弹玩偶效果，以鲸鱼底边中心为原点，按下时底部坐标不变。

  • 代码绘制的气泡

    大椭圆、尾巴与两个小圆沿用原挂件几何，文字三行随气泡开合淡入。

  • 余额

    每 60 秒自动刷新（可调 20 至 600 秒），点击鲸鱼立即刷新，余额变化时数字滚动。

  • 上一轮对话消耗

    刷新时检测到余额下降即弹出消耗气泡，金额取绝对值并以红色显示。

  • 今日已用

    小鲸鱼记账与实时令牌两种模式，令牌模式按峰谷定价换算。

  • 自定义余额

    没有密钥时用任意文本替代余额与今日已用，也可以整体隐藏余额相关内容只留台词。

  • 随机台词

    点击气泡切换台词，含时段提示、动态图与卖萌台词，按权重抽取。

  • 音效

    小黄鸭与音效1两套按压音效，可关闭、可调音量、可试听。

  • 自适应显示

    深浅色主题、系统字号缩放与旋转自适应。

交互

单击鲸鱼
刷新余额并弹出气泡，气泡已打开时只重新计时
单击气泡
第一次切到随机台词，再点一次收起；消耗气泡点击直接收起
拖动鲸鱼
移动桌宠，松手吸附到最近的边，贴左缘整体镜像
通知栏条目
打开设置、立即刷新、收起桌宠
应用图标
打开设置界面

桌宠本身不承载打开设置的手势，应用内的使用说明与此一致：没有双击与长按动作。 拖动越界即停在安全区边界，吸附按松手时的落点判定。气泡自动关闭时间可在设置中调整，设为 0 秒表示不自动收起。

安装

  1. 下载安装包

    页面上的安装包每天由 GitHub Actions 自动构建并同步到这里。

  2. 填写 API Key

    打开应用，在余额一栏填写「API Key」（sk- 开头）。

  3. 授权悬浮窗

    点击「悬浮窗权限」按提示授权，鲸鱼需要绘制在其他应用上层。

  4. 显示桌宠

    打开「显示桌宠」，鲸鱼会从屏幕边缘滑入。

权限说明

SYSTEM_ALERT_WINDOW
在其他应用上层绘制桌宠
FOREGROUND_SERVICE / FOREGROUND_SERVICE_SPECIAL_USE
保持桌宠常驻并显示状态通知
POST_NOTIFICATIONS
展示余额状态通知
INTERNET
请求余额与用量接口
RECEIVE_BOOT_COMPLETED
开机后按设置恢复桌宠
REQUEST_IGNORE_BATTERY_OPTIMIZATIONS
由用户决定是否加入电池优化白名单

API Key 与平台令牌只保存在应用私有存储中，仅用于请求 DeepSeek 接口。

设计说明

  • 反馈发生在按下瞬间：按压形变与按压音效同时开始，松手音效按按压样本的剩余时长排程。
  • 按压形变用时 0.22 秒的 CSS cubic-bezier(.34,1.56,.64,1)，先过冲再回到原尺寸。
  • 位置结算与尺寸变化走 0.16 秒与 0.28 秒的 CSS ease 补间；拖动期间坐标直接跟随手指。
  • 拖动越界即停在安全区边界，不做阻尼；吸附目标取自松手时的落点。
  • 动画由 Choreographer 推帧，只在有动画进行时请求下一帧。
  • 气泡三个图形错峰弹出，文字延后 0.36 秒淡入，内容切换先淡出、替换、再淡入。
  • 系统关闭动画后，位移与形变直接落位，气泡内容立即替换。
  • 字号越大字距越紧、行高越紧，字重承担层级。
  • 气泡内容只由一处入口给出：隐藏余额、自定义余额、自定义今日已用、显示今日已用这些开关只改变取到的文本， 气泡、时段台词、设置页预览与通知栏消费同一份结果。

尺寸自适应只有两个来源：布局间距与圆角来自屏幕短边的比例并限定上下限，文字跟随系统字号， 桌宠的绘制全部以 1026x1026 的画布单位为基准按比例缩放，源码中不存在按屏幕写死的像素值。

已知限制

  • 鲸鱼与气泡各占一个矩形窗口，窗口分别收紧到各自实际绘制的像素外接框，窗口内没有绘制到的像素不会继续传给下层应用。
  • 气泡展开期间，气泡窗口与鲸鱼重叠的那一块无法抓取鲸鱼。
  • 显示桌宠需要悬浮窗权限，未授权时打开开关会先跳转授权页。
  • 后台保活依赖前台服务与电池优化白名单，设置页提供两个跳转入口； 国产系统的自启动与后台限制还需在系统设置里单独放行。
